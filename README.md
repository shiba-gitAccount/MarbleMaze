



# Marble Maze

マウスでステージを傾け、重力を操ってゴールを目指す物理パズルゲームです。

## 🛠 作品概要
- **開発期間**: 約2ヶ月（実制作日数：約3日）
- **操作方法**: マウスドラッグによるステージの傾斜操作

## 🏗 ステージ構成
- **Stage 1 [Tutorial]**: 基本操作を学ぶためのシンプルな構造。
- **Stage 2 [Dynamics]**: 加速床と動く壁を導入し、アクション性を強化。
- **Stage 3 [Puzzle]**: 障害ブロック、スイッチ、ゲートを組み合わせたギミック面。

## 💡 技術的なこだわり・苦労した点

### 1. 物理挙動の最適化と「1/16スケール」の採用
プレイヤーが遠心力を利用したジャンプ（ショートカット）を試みた際、落下速度が速すぎてステージをすり抜ける問題に直面しました。
単に重力を弱めると移動が遅くなり爽快感が損なわれるため、**「ステージ全体のスケールを当初の1/16にする」**ことで、見た目の速度感を維持したまま、物理演算上の落下速度を制御し、すり抜け防止と爽快感を両立させました。

### 2. 加速床のフィーリング調整
加速の演出について「速度の直接変更」「持続的な力」「瞬間的な力」の3パターンを検証しました。
最終的に、**「踏んだ瞬間にImpulse（瞬間的な力）を加える」**仕様を採用。これにより、プレイヤーが加速を明確に実感できるキレのある挙動を実現しました。

### 3. ConfigurableJointによるオブジェクト制御
ステージ3の障害物（箱）において、物理挙動を維持しつつ「余計な回転」を抑える必要がありました。
完全に固定するのではなく、**ConfigurableJointを使用してステージ（親）の角度変化にのみ同期させる**ことで、ステージの傾きには追従しつつ、衝突による不自然な回転を防ぎ、パズルとしての解きやすさを向上させました。
